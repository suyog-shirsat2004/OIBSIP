## Project Overview

Predict product sales based on advertising spend across TV, Radio, and Newspaper channels.

## Technologies Used

* Python
* Jupyter Notebook
* Scikit-learn
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Models Used

* Linear Regression
* Lasso Regression
* Ridge Regression
* Random Forest Regressor

## Dataset

The Advertising dataset contains sales figures across 200 markets with advertising budgets for TV, Radio, and Newspaper.

## Project Objective

To build a regression model that predicts sales based on advertising spend across different media channels.
