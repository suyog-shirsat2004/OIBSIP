# Iris Flower Classification

## Live Notebook
[Open Iris_Flower_Classification.ipynb](https://github.com/suyog-shirsat2004/OIBSIP/blob/main/Task-1/Iris_Flower_Classification.ipynb)

This project uses Machine Learning to classify iris flowers into:

* Setosa
* Versicolor
* Virginica

## Tools & Technologies

* Python
* Jupyter Notebook
* Scikit-learn
* Pandas
* NumPy

## Project Objective

The objective of this project is to train a machine learning model that can classify iris flowers based on their measurements.
