## Project Overview

Classify emails as spam or ham (non-spam) using Natural Language Processing and Machine Learning techniques.

## Technologies Used

* Python
* Jupyter Notebook
* Scikit-learn
* Pandas
* NumPy
* Matplotlib
* Seaborn
* NLTK

## Dataset

The SMS Spam Collection dataset contains 5,572 SMS messages labeled as spam or ham.

## Models Used

* Multinomial Naive Bayes
* Logistic Regression
* Support Vector Machine (SVM)

## Project Objective

To build a text classification model that accurately identifies spam messages using TF-IDF vectorization and machine learning algorithms.
